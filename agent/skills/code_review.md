description: Perform a comprehensive, senior-level code review on a diff, file, or implementation.
---

When reviewing code:
1. Examine correctness, boundary conditions, edge cases, and type safety.
2. Check for security vulnerabilities, injection risks, authorization bypasses, and credential exposure.
3. Assess architecture and maintainability: modularity, single responsibility, and clean abstraction boundaries.
4. Verify performance: unnecessary re-renders, unindexed database queries, memory leaks, and blocking synchronous I/O.
5. Provide clear, actionable feedback with specific code recommendations and diffs.
